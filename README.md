# PawPals - Your Daily Pal!

PawPals is a modern, responsive browser-based pet care and vaccination management application designed for pet owners. It enables users to easily track pet profiles, schedule appointments, record vaccination histories, and manage care reminders from a single, centralized dashboard.

---

## Features

* **Interactive Dashboard:** Live visual summary cards for total pets, upcoming appointments, and urgent reminders.
* **Pet Profile Management:** Register pets, edit profiles, or delete records dynamically.
* **Appointment Scheduler:** Schedule visits with vet details and automated form constraints to prevent past-date selections.
* **Medical Records Log:** Track medical history and status for vaccinations and checkups.
* **Care Reminders & Task Transfer:** Complete care tasks and automatically convert active reminders into historical medical records.
* **Empty State Handling:** UI placeholders ensure smooth layouts even when tables or lists are empty.
* **Auth UI State:** Toggle simulated login/logout states directly in the main header.

---

## Built With

* **HTML5:** Semantic layout, accessible form structures, and native templates.
* **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, and responsive styling.
* **JavaScript (ES6+):** Dynamic DOM manipulation, template cloning, date validation, and interactive state management.
